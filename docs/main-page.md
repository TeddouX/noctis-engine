# Noctis Engine {#noctis_engine}

Noctis Engine is a C++ ECS based game engine. I created it as a hobby so there may be a lot of bugs and performance issues.
If you find any, feel free to contribute to the [github repo](https://github.com/TeddouX/noctis-engine), any help will be welcomed. 

To understand how to get started with the engine, go see: @subpage getting_started.  
To get a feel for more core functionalities, go see: @subpage core_functionalities.
