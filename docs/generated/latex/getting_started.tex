\hypertarget{getting_started_autotoc_md0}{}\doxysubsection{\texorpdfstring{What is Noctis Engine ?}{What is Noctis Engine ?}}\label{getting_started_autotoc_md0}
Noctis Engine is first of all an ECS (entity component system) based game engine written entirely in cpp. ~\newline
 It uses Open\+GL as its graphics API. I know Open\+GL is old and now falling behind on features (raytracing, etc...), but it\textquotesingle{}s the easiest of all graphics APIs to use and understand, which for me is a selling point because I am not a specialist in graphics programming. If you want to add implementation for newer graphics APIs like Vulkan or DX12, please contribute to the \href{https://github.com/TeddouX/noctis-engine}{\texttt{ github repo}}. ~\newline
 The engine is entirely based in code, that means no GUIs (this might change in the future with the addition of helpers to create levels for example), everything you want to do is written in code. This lets you control resources, memory, rendering and many more things manually. ~\newline
\hypertarget{getting_started_autotoc_md1}{}\doxysubsection{\texorpdfstring{How do I use it for my game ?}{How do I use it for my game ?}}\label{getting_started_autotoc_md1}
Noctis Engine is based on \href{https://cmake.org/}{\texttt{ CMake}} so you need to have it installed on your system and have a little understanding of how it works. I don\textquotesingle{}t provide pre-\/built binaries for now because the engine is too early in its development cycle, so you have to build it yourself. ~\newline
 The easiest way to do that is to use \href{https://git-scm.com/book/en/v2/Git-Tools-Submodules}{\texttt{ git submodules}}. ~\newline
 You first need to initialize git in your project\textquotesingle{}s folder using the command\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{git\ init}

\end{DoxyCode}


You then need to add the Noctis Engine github repo as a submodule for your project\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{mkdir\ thirdparty}
\DoxyCodeLine{git\ submodule\ add\ https://github.com/TeddouX/noctis-\/engine\ thirdparty/noctis-\/engine}

\end{DoxyCode}


This command will place the Noctis Engine github repository under the {\ttfamily thirdparty/} folder. ~\newline
 After adding the engine as a submodule, you need to add it as a subdirectory in your project\textquotesingle{}s {\ttfamily CMake\+Lists.\+txt} for it to be built\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{add\_subdirectory("{}thirdparty/noctis-\/engine"{})}

\end{DoxyCode}


To link the library to your project, use\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{target\_link\_libraries(my\_project\ PRIVATE\ noctis\_engine::noctis\_engine)}

\end{DoxyCode}


Congratulations ! You now have added Noctis Engine to your project and you can use all its features.\hypertarget{getting_started_autotoc_md2}{}\doxysubsection{\texorpdfstring{Where do I get started ?}{Where do I get started ?}}\label{getting_started_autotoc_md2}
\hypertarget{getting_started_autotoc_md3}{}\doxysubsubsection{\texorpdfstring{The window}{The window}}\label{getting_started_autotoc_md3}
The window is one of the most important elements of any games. Noctis Engine uses the \doxylink{classNoctisEngine_1_1Core_1_1Window}{Window} class as its abstraction layer over an API called GLFW. This makes windowing cross platform and easy to use. ~\newline
 The window is also what holds the Open\+GL context, necessary for drawing anything to the screen. Without it, calling rendering functions and using rendering objects will result in your program SEGFAULT\textquotesingle{}ing because Open\+GL functions aren\textquotesingle{}t initialized and point to NULL. ~\newline
 To create a window, use the \doxylink{classNoctisEngine_1_1Core_1_1Window_a26680fcbd217f62e0cd20ee4fd68f0c3}{window\textquotesingle{}s constructor} defined in the \doxylink{window_8hpp_source}{window.\+hpp} header\+:
